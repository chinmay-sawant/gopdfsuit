# PR - templates for shipping

Use these templates when opening a GitHub PR, issue, or progress comment so every thread has the same shape.

## Templates in this skill

- `PR_TEMPLATE.md` - PR title convention, summary, changes, impact table, test plan, related issues, and `gh pr create` with `--assignee "@me"` and labels
- `ISSUE_TEMPLATE.md` - context, scope, out of scope, success criteria, and `gh issue create`
- `COMMENT_TEMPLATE.md` - factual progress updates without chatty trailing prompts

Load the relevant template file and follow it verbatim.
